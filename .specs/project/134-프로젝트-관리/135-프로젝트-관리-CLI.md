## 개요
터미널 환경에서 프로젝트를 생성하고 목록을 조회할 수 있는 CLI 도구.

## 요구사항

- [ ] `thetable project create` 명령어 구현 (대화형/비대화형)
- [ ] `thetable project list` 명령어 구현 (페이지네이션, 필터링)

## 인터페이스

### CLI - 프로젝트 생성

```bash
# 대화형 생성
thetable project create

# 옵션 지정 생성
thetable project create \
  --name "주간 개발 회의" \
  --profile config/agent_profiles.yaml \
  --agenda config/agendas.yaml \
  --mcp github
```

**대화형 플로우:**

```
$ thetable project create
프로젝트 이름: 주간 개발 회의
설명 (선택): 매주 월요일 개발팀 정기 회의
에이전트 프로필 경로 [config/agent_profiles.yaml]:
안건 경로 [config/agendas.yaml]:
MCP 서버 (콤마 구분) [github]:

✅ 프로젝트 '주간 개발 회의' 생성 완료 (id: 550e8400...)
```

### CLI - 목록 조회

```bash
# 기본 조회
thetable project list

# 옵션 지정 조회
thetable project list --page 1 --limit 10 --status active
```
