# GitHub 이슈 vs 문서 Gap 분석 리포트

> 작성일: 2026-02-13
> 목적: 현재 문서(`docs/`)와 GitHub 이슈 간의 불일치 항목 및 추가 제안 사항 정리

## 1. 문서에는 있으나 이슈에 없는 항목 (Phase 1 기준)

다음 항목들은 `docs/roadmap.md`의 Phase 1(우선순위 높음)에 명시되어 있으나, 현재 Open된 이슈에서 구체적인 작업으로 확인되지 않는 항목입니다.

### 1.1 회의록 영속화 (Persistence)
- **문서 내용**: "회의록 저장 및 조회 기능 제공", "JSON/Markdown/DB 저장" (`roadmap.md` Phase 1)
- **현황**: `MeetingState`를 메모리 상에서 관리하는 이슈(#141)는 있으나, 이를 파일이나 DB로 영구 저장하는 구체적인 이슈가 부재합니다.
- **필요 조치**: 회의 종료 시점 또는 주기적으로 회의 내용을 저장하는 기능 구현 이슈 추가 필요.

### 1.2 5명 이상 에이전트 확장 및 성능 검증
- **문서 내용**: "5명 이상 에이전트로 확장 시 안정적 운영", "성능 테스트" (`roadmap.md` Phase 1)
- **현황**: 현재 이슈들은 기능 구현에 초점이 맞춰져 있으며, 다수 에이전트 참여 시의 부하 테스트나 `refill_speakers` 로직의 최적화 관련 이슈는 보이지 않습니다.
- **필요 조치**: 에이전트 5인 이상 참여 시나리오 테스트 및 성능 최적화 이슈 추가 필요.

### 1.3 에러 복구 로직 (Error Recovery)
- **문서 내용**: "LLM/MCP 도구 실패 시 재시도 및 복구", "Exponential backoff" (`roadmap.md` Phase 1)
- **현황**: LLM 호출 실패나 MCP 도구 실행 오류 발생 시의 재시도/복구 메커니즘에 대한 구체적인 구현 이슈가 없습니다.
- **필요 조치**: Resilience 관련 공통 모듈 또는 데코레이터 구현 이슈 추가 필요.

### 1.4 LLM 호출 최적화
- **문서 내용**: "매 발언마다 호출 → 정규표현식 우선", "안건 업데이트 주기 조정" (`roadmap.md` Phase 1)
- **현황**: 멘션 추출(#118) 등 일부는 완료되었으나, 안건 업데이트 주기 조정이나 토큰 절약을 위한 추가적인 최적화 작업 이슈가 명시적이지 않습니다.

### 1.5 회의록 및 액션 아이템 자동화
- 회의 종료 후 전체 요약문 생성
- 결정된 사항(Decision)과 향후 할 일(Action Item) 자동 추출 및 정리
- 회의록 PDF/HTML 내보내기
