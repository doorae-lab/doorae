# TUI 인터페이스 가이드

Doorae TUI는 Textual 기반의 대화형 회의 인터페이스입니다. 터미널에서 실시간 스트리밍, 안건 추적, 참여자 상태를 한 화면에서 확인할 수 있습니다.

---

## TUI 활성화 조건

TUI는 다음 조건을 모두 충족할 때 자동 활성화됩니다:

- `--classic` 플래그가 없을 것
- stdout이 TTY일 것 (파이프라인이 아닌 대화형 터미널)
- 터미널 크기가 80x24 이상일 것

조건을 충족하지 못하면 자동으로 classic 모드로 전환됩니다.

## 화면 구성

```
┌─────────────────────────────────────────────────────────────────┐
│  Header (Doorae 타이틀 + 발언자 정보)                            │
├───────────────────────────────────────┬─────────────────────────┤
│                                       │  📋 안건 진행 상태       │
│  대화 영역 (conversation-scroll)       │  ⏱ 총 경과: 03:42       │
│                                       │  ──────────────────      │
│  ┌─ [Host] ─────────────────────┐     │  🔄 1. 로드맵 논의  ◀    │
│  │ 안녕하세요, 회의를 시작...     │     │  ⏳ 2. 달성 계획         │
│  └──────────────────────────────┘     │  ⏳ 3. 스프린트 리뷰     │
│                                       │                         │
│  ┌─ [PM] ───────────────────────┐     ├─────────────────────────┤
│  │ 현재 프로젝트 상황을 보고...   │     │  👥 참여자               │
│  │   ┌─ Backend (위임) ─────┐   │     │  🗣️ Host (host) [발언 중]│
│  │   │ API 관련 의견은...    │   │     │  ⚪ PM (pm) [대기 중]     │
│  │   └─────────────────────┘   │     │  ⚪ TechLead (tech_lead) │
│  └──────────────────────────────┘     │    ⚪ Backend            │
│                                       │    ⚪ Frontend           │
├───────────────────────────────────────┴─────────────────────────┤
│  의견을 입력하세요 · Enter: 전송 · Ctrl+J: 줄바꿈                │
│  [입력 영역]                                                     │
├─────────────────────────────────────────────────────────────────┤
│  Footer (키 바인딩 안내)                                         │
└─────────────────────────────────────────────────────────────────┘
```

### 영역별 설명

| 영역 | 위치 | 역할 |
|------|------|------|
| Header | 상단 | 앱 타이틀, 현재 발언자, Room ID (서버 모드) |
| 대화 영역 | 좌측 메인 | 에이전트 발언이 실시간 스트리밍으로 표시 |
| 안건 패널 | 우측 상단 | 안건 진행 상태, 경과 시간, 현재 안건 표시 |
| 참여자 패널 | 우측 하단 | 참여자 계층 구조와 실시간 상태 |
| 입력 패널 | 하단 | 사용자(is_human) 차례에 활성화 |
| Footer | 최하단 | 사용 가능한 키보드 단축키 |

---

## 키보드 단축키

| 키 | 동작 |
|----|------|
| `Ctrl+Q` | 회의 종료 |
| `Ctrl+C` | 회의 종료 (숨김) |
| `?` | 도움말 표시 |
| `Page Up` | 대화 영역 위로 스크롤 |
| `Page Down` | 대화 영역 아래로 스크롤 |
| `Ctrl+D` | 위임된(delegated) 발언 표시/숨김 토글 |
| `Enter` | 입력 전송 (입력 패널 활성 시) |
| `Ctrl+J` | 줄바꿈 삽입 (입력 패널 활성 시) |

## 안건 패널 읽기

안건 패널은 회의의 구조화된 진행 상태를 실시간으로 보여줍니다.

### 상태 아이콘

| 아이콘 | 상태 | 의미 |
|--------|------|------|
| ⏳ | `pending` | 아직 시작하지 않은 안건 |
| 🔄 | `in_progress` | 현재 논의 중인 안건 |
| ✅ | `completed` | 완료된 안건 |
| ⏸️ | `deferred` | 보류된 안건 |

### 표시 형식

```
⏱ 총 경과: 05:23
──────────────────
✅ 1. 프로젝트 로드맵 논의 [02:15]
   └─ LLM 기반 회의 시스템 v1 로드맵 확정
🔄 2. 프로젝트 달성 계획 [01:48] ◀
⏳ 3. 스프린트 리뷰
⏳ 4. 스프린트 계획
```

- `◀` 마커: 현재 진행 중인 안건
- `[MM:SS]`: 해당 안건의 소요 시간 (진행 중이면 실시간 업데이트, 완료되면 최종 시간)
- `└─`: 안건의 결정 사항 (Host가 완료 선언 시 표시)

## 참여자 패널 읽기

참여자 패널은 에이전트의 계층 구조와 현재 상태를 트리 형태로 표시합니다.

### 상태 아이콘

| 아이콘 | 상태 | 의미 |
|--------|------|------|
| ⚪ | `idle` | 대기 중 |
| 🗣️ | `speaking` | 발언 중 |
| 🔧 | `tool_calling` | MCP tool 호출 중 |
| ⌨️ | `waiting_input` | 사용자 입력 대기 |
| 🔌 | `offline` | 연결 끊김 (서버 모드) |

### 계층 구조 예시

```
👥 참여자
🗣️ Host (host) [발언 중]
⚪ PM (project_manager) [대기 중]
⚪ TechLead (tech_lead) [대기 중]
   ⚪ Backend (backend_engineer) [대기 중]
   ⚪ Frontend (frontend_engineer) [대기 중]
```

최상위 에이전트(Host, PM, TechLead)는 기본 펼침 상태이고, sub-agent(Backend, Frontend)는 부모 아래에 들여쓰기되어 표시됩니다.

---

## 대화 영역의 발언 표시

### 일반 발언 (SpeechBubble)

각 에이전트의 발언은 고유 색상의 좌측 테두리로 구분됩니다. 스트리밍 중에는 실시간 텍스트가 표시되고, 발언이 완료되면 Markdown으로 렌더링됩니다.

`@멘션` 패턴은 자동으로 강조 표시됩니다.

### 위임된 발언

supervisor가 sub-agent에게 위임한 발언은 들여쓰기와 반투명 스타일로 구분됩니다:

```
[TechLead]
기술적 세부 사항은 Backend에게 확인하겠습니다.
  ┌ Backend (위임) ─────────────────────┐
  │ API 엔드포인트 설계 관련해서...       │
  └─────────────────────────────────────┘
```

`Ctrl+D`로 위임 발언 표시를 토글할 수 있습니다.

### Tool 호출 인디케이터

에이전트가 MCP tool을 호출하면 spinner 애니메이션이 표시됩니다:

```
[PM]
⚙ github_list_issues (실행 중...)
```

tool 호출이 완료되면 spinner가 사라지고 응답이 이어집니다.

## 사용자 입력

`agent_profiles.yaml`에서 `is_human: true`로 설정된 참여자의 차례가 오면 입력 패널이 활성화됩니다.

활성화 시 라벨 변경:

```
[alice의 차례] 프로젝트 로드맵 논의 · Enter: 전송 · Ctrl+J: 줄바꿈
```

서버 모드에서 다른 사용자가 입력 중이면:

```
[alice님이 입력 중] 프로젝트 로드맵 논의
```

## 서버 모드 TUI

`doorae create` 또는 `doorae join`으로 서버에 접속하면 TUI에 추가 정보가 표시됩니다:

- Header sub-title에 Room ID 표시
- 연결 상태 표시 (연결 중, 재연결 중)
- 초대 명령어 안내 (방 생성 시)

연결이 끊기면 자동 재연결을 시도하며, 상태 바에 `reconnecting` 상태가 표시됩니다.

---

## 회의 종료

회의가 종료되면 (Host가 종료 선언 또는 모든 안건 완료) 요약 정보가 표시됩니다:

- 완료된 안건 수 / 전체 안건 수
- 각 참여자별 발언 횟수

`Ctrl+Q`를 누르면 즉시 종료됩니다.
