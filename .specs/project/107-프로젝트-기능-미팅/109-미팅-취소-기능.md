# 미팅 취소 기능

- 이슈: #109
- Epic: #107 프로젝트 기능
- 상태: draft
- 작성일: 2026-02-10

## 개요

생성된 미팅을 취소(삭제)하는 기능.

## 요구사항

- [ ] 미팅 상태가 `created` 또는 `scheduled`일 때만 취소 가능
- [ ] 진행 중인 미팅은 취소 불가 (종료 후 삭제 필요)

## 인터페이스

### REST API

#### 미팅 취소

```
DELETE /api/projects/{id}/meetings/{meeting_id}
```

**Response (204 No Content)**

**에러 응답:**

| 코드 | 상황 |
|------|------|
| `401` | 인증 실패 |
| `404` | 미팅이 존재하지 않음 |
| `409` | 진행 중인 미팅은 취소 불가 |
