# 기여하기

Doorae 프로젝트에 관심을 가져주셔서 감사합니다!
Doorae는 AI 에이전트와 사람이 함께 일하는 팀 워크스페이스를 만드는 오픈소스 프로젝트입니다.
모든 형태의 기여를 환영합니다.

## 기여 방법

### :material-code-braces: 코드 기여

버그 수정, 새로운 기능 구현, 성능 개선 등 코드 기여를 환영합니다.

1. [개발 환경 설정](development-setup.md)을 따라 로컬 환경을 구성하세요
2. [코드 구조](code-structure.md)를 파악하세요
3. 이슈를 확인하거나 새로운 이슈를 생성하세요
4. Fork 후 feature branch에서 작업하세요
5. [테스트](testing.md)를 작성하고 통과시키세요
6. Pull Request를 제출하세요

### :material-file-document-edit: 문서 기여

문서 개선, 오타 수정, 번역, 새로운 가이드 작성 등을 환영합니다.

- 문서는 `docs/` 디렉토리에 위치합니다
- [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) 형식을 사용합니다
- 한국어로 작성하되, 기술 용어는 영어를 유지합니다

### :material-bug: 이슈 리포트

버그를 발견하셨나요? GitHub Issues에 리포트해주세요.

- 재현 가능한 단계를 포함해주세요
- Python 버전, OS, 관련 환경 정보를 명시해주세요
- 가능하다면 에러 로그를 첨부해주세요

### :material-test-tube: 테스트 기여

테스트 커버리지 향상은 프로젝트의 안정성에 직접적으로 기여합니다.

- 누락된 테스트 케이스 추가
- Edge case 테스트 작성
- Integration 테스트 보강

자세한 내용은 [테스트 가이드](testing.md)를 참고하세요.

## 행동 강령

이 프로젝트는 모든 참여자가 존중받는 환경을 지향합니다.

- 건설적이고 친절한 커뮤니케이션을 유지해주세요
- 다양한 의견과 경험을 존중해주세요
- 비판은 코드에 대해, 사람에 대해서는 하지 말아주세요
- 포용적인 언어를 사용해주세요

## 질문이 있으신가요?

- GitHub Issues에서 `question` 라벨로 질문을 남겨주세요
- 기존 이슈와 Discussion을 먼저 검색해보세요
